# Agentic Workflow Rules: BMAD + Superpowers

1. Planning & Architecture (BMAD):
   - Use BMAD personas (/analyst, /architect, /pm) to generate project specifications.
   - All feature requirements must be documented in `docs/specs/` or BMAD story files before writing code.

2. Execution & Coding (Superpowers):
   - For every task generated by BMAD, invoke Superpowers implementation skills.
   - Enforce Superpowers TDD: Always write failing tests first before feature implementation.
   - Use Superpowers sub-agent execution to work through individual BMAD task stories.

3. Quality Assurance & Signoff (BMAD):
   - Once Superpowers tests pass and verification gates clear, invoke the BMAD QA persona (/qa) to validate against the initial PRD.
